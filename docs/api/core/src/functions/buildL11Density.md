# Function: buildL11Density()

> **buildL11Density**(`density`): `Uint8Array`

`1F 70 02 DD` — set print density. `DD` is the L11 density value
(the firmware clamps; the catalogue scale is 1 light / 2 normal /
3 dark).

## Parameters

### density

`number`

## Returns

`Uint8Array`
